# 🚴 Super Bikes

Projeto de e-commerce desenvolvido para a disciplina de **Desenvolvimento Web com .NET e Bases de Dados**.

A aplicação simula uma loja virtual especializada na venda de bicicletas, acessórios e produtos relacionados ao ciclismo, utilizando ASP.NET Core, Razor Pages e integração com banco de dados.

---

# 📚 Sobre o Projeto

O objetivo deste projeto é aplicar conceitos de:

- Desenvolvimento Web com .NET
- Estruturação de aplicações ASP.NET Core
- Razor Pages
- HTML, CSS e Bootstrap
- Organização de páginas e layouts
- Integração com banco de dados
- Boas práticas de programação

# ▶️ Como Executar o Projeto

## 1️⃣ Clonar o repositório

```bash
git clone https://github.com/Jowltenha/SuperBicicletas2026App.git
```

---

## 2️⃣ Abrir o projeto

Abra a solução no:

- Visual Studio 2022

---

## 3️⃣ Restaurar dependências

O Visual Studio normalmente faz isso automaticamente.

Ou utilize:

```bash
dotnet restore
```

---

## 4️⃣ Executar o projeto

```bash
dotnet run
```

Ou pressione:

```bash
CTRL + F5
```
